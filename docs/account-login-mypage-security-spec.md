# 로그인·마이페이지·보안 기능 명세

## 기준

- 기준 브랜치: `fix/mypage-existing-api-connections`
- 비교 대상: 최신 `upstream/merge` 포함
- 기존 신고·거래 작업은 유지하고, 이 문서는 현재 구현을 기준으로 갱신한다.

## 로그인 및 계정

1. 회원가입과 로그인은 이메일 정규화, 비밀번호 정책, BCrypt 해시, JWT 토큰 버전을 사용한다.
2. 이름 변경, 판매자 신청, 진행 거래 확인 후 탈퇴를 지원한다.
3. 비밀번호 변경은 현재 비밀번호를 재검증하고 새 비밀번호 정책·확인을 통과해야 한다. 변경 시 토큰 버전을 올려 기존 JWT를 폐기한다.
4. 탈퇴·정지 계정은 일반 JWT를 발급받거나 보호 API를 사용할 수 없다.

## 마이페이지

1. 구매·판매·제안·채팅은 로그인 사용자 ID를 기준으로 기존 도메인 API 결과를 합쳐 표시한다.
2. 거래 상태는 제안, 진행, 완료를 포함하며 완료 거래만 별도 이력처럼 표현한다.
3. 신고 작성은 대상 문맥과 스냅샷, 선택 이미지 최대 3개를 한 요청으로 저장한다.
4. 신고 본문과 증거는 관리자 전용이다. 신고자 API에는 처리 상태, 관리자 결과, 처리 시각만 반환한다.

## 정지 및 해명

1. 기간 제재는 1·3·7·15·30일이며 만료 시 자동 해제한다.
2. 수동 정지는 사유를 필수로 저장하고 관리자 해제 전까지 유지하며 기간 제재 만료가 이를 해제하지 않는다.
3. 정지 사용자가 올바른 계정 정보로 로그인하면 JWT 대신 `423 Locked`와 정지 사유·기한을 받고 `/suspended`로 이동한다.
4. 정지 페이지는 사유, 종료 시각 또는 무기한 상태를 표시한다. 해명 제출은 비밀번호를 다시 확인한 뒤 기존 관리자 신고함에 문의로 등록한다.

## 보안 및 운영

1. `/api/v1/admin/**`는 관리자만, 일반 `/api/**`는 인증 사용자만 접근한다. 정지 해명 API만 자격 재검증을 전제로 공개 경로에 둔다.
2. 신고는 대상 소유·대화 참여 관계를 서버에서 검증하고, 중복 신고와 시간당 10건 초과를 차단한다.
3. 관리자 처리 이력, 제재 발급·해제, 신고 스냅샷은 감사 근거로 보존한다.

## 페이징·필터 최적화 방향

1. 구매·판매·제안·채팅 목록 API는 선택적으로 `page`, `size`, `status`를 받고 페이지 응답을 반환한다. 파라미터가 없는 기존 호출은 배열 응답을 유지해 기존 화면을 회귀시키지 않는다.
2. 기본 정렬은 `createdAt DESC, id DESC`, 페이지 크기는 20, 최대 100으로 제한한다.
3. 거래·제안·채팅에는 구매자 또는 판매자, 상태, 생성 시각 순서의 복합 인덱스를 둔다. 여러 도메인을 합치는 거래 활동은 합성 후 안정 정렬·필터·페이지 절단한다.
4. 초기에는 번호 기반 페이지를 유지하고 데이터가 커지면 동일 정렬 키의 커서 방식으로 전환한다. 상태별 개수는 별도 집계 API 또는 캐시로 분리한다.

## 남은 연동

1. 마이페이지 목록은 화면 포커스 복귀·탭 복귀 후 15초 이상 경과했거나, 열린 상태로 60초가 지나면 원본 API를 다시 조회한다.
2. 신고 처리 결과를 별도 알림함으로 푸시하는 기능은 없으며 현재는 결과 조회 API까지만 제공한다.
